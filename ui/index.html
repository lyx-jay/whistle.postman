What are Whistle Rules?

Whistle rules allow you to intercept and modify HTTP requests/responses. Use them to:

  • Mock - Return fake responses without hitting the server
  • Redirect - Forward requests to another URL or local server
  • Delay - Simulate slow network conditions
  • Throttle - Limit bandwidth for testing
